# Tabarik releases

Signed installers for the Tabarik rental portfolio app. This repository holds only release files: no source code and no data.

**Install on a Windows PC:** download [Tabarik-Setup.exe](https://github.com/hisXLNC/tabarik-releases/releases/latest/download/Tabarik-Setup.exe) and run it. It installs for the current Windows user (no administrator rights needed). After that Tabarik keeps itself up to date.

Each update is signed. Tabarik checks the signature before installing and refuses anything that isn't signed with Tabarik's key.
